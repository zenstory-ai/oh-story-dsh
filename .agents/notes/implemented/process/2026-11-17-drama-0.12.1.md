# Agent Note: 同步 Drama Skills 0.12.1

Status: implemented

## Problem

Drama Skills 0.12.1 在 0.12.0 的五份创作文档契约上补齐从真实短剧或漫剧成片反推标准《剧本.md》的流程：烧录字幕拼版带编号和起止时间，转写可以把编号映射回时间轴，代表帧拼图补充镜号、时间与长首尾镜抽帧，审查侧新增台词与画面校对规则。上游同时修复反推说明仍引用退役 `设定集/`、默认字幕框漏字，以及部分测量与跨集连戏误判。

## Decision

- 从上游发布标签 `v0.12.1` 同步 12 个 Skills，固定提交为 `37232f6d22e174c36e321d2e3a1a3ae871e7d602`，继续由 `packages/knowledge/drama/manifest.json` 记录逐文件哈希。
- 保持现有 DSH bridge、演示 fixture 内容、工作台解析和原生浏览器测试不变。0.12.1 只扩展 `short-drama-breakdown` 的测量脚本、反推说明、路由描述与 `short-drama-review` 的校对规则，没有修改五份创作者 Markdown、生产 adapter、成片目录或工作台读取契约。
- README 与架构文档的当前 Drama Skills 版本更新为 0.12.1；`scripts/demo-fixtures/sources.json` 与 README 中的公开样例来源提交随固定版本更新。0.12.1 未改示例文件，因此五份演示 fixture 内容无需重写。

## Alternatives considered

- 同步知识资产时一并改 DSH bridge 或演示 fixture：上游补丁没有跨越这些边界，额外改动既无新契约依据，也会把非破坏性上游同步扩大为无关的产品行为变更。
- 保留演示 fixture 的 0.12.0 provenance：`check-drama-parity.ts` 要求样例来源与固定资产使用同一上游提交；0.12.1 的样例内容未变，更新 provenance 可同时保持门禁一致和内容可复核。

## Consequences

短剧拆解可以直接按带编号的烧录字幕拼版校对并反推《剧本.md》，需要完整还原时再切单镜；既有项目配置和文档字段无需迁移。固定资产增加的主要体积来自 `breakdown_tool.py` 的字幕与时间轴能力，插件运行边界和生产权限不变。

## Verification

- `pnpm assets:check` 验证 Drama Skills 0.12.1 的 12 个 Skills、逐文件哈希与 7 个 Python selftests。
- `pnpm --filter @oh-story/dsh test` 验证打包知识资产与插件现有单元契约。
