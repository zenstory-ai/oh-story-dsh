# 没有采集脚本的平台：作者提供榜单

知乎盐言、番茄短篇、七猫短篇等平台目前没有采集脚本，需要作者提供榜单。作者选了这些平台才读本文。

## 向作者要什么

「这个平台我没法自动抓，麻烦把榜单截图或复制的文字发给我，最好带上书名、作者、题材/标签、字数、热度（赞同、收藏、在读都行），有简介更好。给个链接也行，我试着打开。」

- 链接 → 用 WebFetch 抓取；抓不到就请作者改发截图或文字
- 只有故事名列表 → 可以直接分析，但报告的可信度写低一档

## 整理成文件再聚合

把作者给的内容整理成下面的格式，存进本次输出目录（文件名 `{平台}{榜单}_{YYYYMMDD}.md`），再和脚本采集的榜单一起聚合：

```markdown
# 知乎盐言 · 热门榜

### #1 {书名}
*{作者} · {题材} · {状态} · {字数}字 · {热度数字}收藏*
**标签：** {标签1}、{标签2}

> {简介}
```

热度写成「数字 + 口径」（如 `2.3万收藏`、`1.2万热度`），聚合才认得。缺的字段直接省略，不要编。

## 知乎盐言分析维度

| 维度 | 看什么 |
|---|---|
| 热门榜单 | 当前最受关注的故事 |
| 高赞故事 | 口碑最好的作品结构 |
| 新作者上榜 | 非头部账号的题材选择与开篇模式 |
| 付费转化 | 哪些题材读者愿意付费 |
| 标签分布 | 热门标签的变化趋势 |
