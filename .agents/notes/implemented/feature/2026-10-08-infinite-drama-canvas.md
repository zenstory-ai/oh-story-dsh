# Agent Note: 短剧生产「画布」改为无限画布（平移 + 以光标为中心缩放）

Status: implemented

## Problem

「画布」页原来是一块固定 1800×1800 的 div，用 `transform: scale()` 缩放，视野靠外层 `overflow: auto` 滚动。2026-10-08 实测（DSH 0.2.1-alpha.1，EP001 演示工作区）确认：

- 缩放只改 transform，浏览器不重算滚动范围：180% 时最后一个镜头（y≈5486）滚不到，50% 时留下大片空白。
- 节点可以拖到负坐标，滚动条到 0 也看不到，只能「复位」清掉整集布局。
- 不能拖背景平移，滚轮只滚动不缩放，缩放以左上角为原点。
- 画布外框高度写死为 `calc(100% - 84px)`，没扣掉上方面板，底部被推出窗口，出现双层滚动。
- 别处选中（或 Agent 用 `oh_story_production` 聚焦）的镜头不会被带进视野；单击节点不能选中，Enter 不能打开原文。

## Decision

- 画布组件拆到 `packages/dsh-plugin/src/client/production-canvas.tsx`，视野数学放在 `canvas-viewport.ts`：屏幕坐标 = 世界坐标 × zoom + pan。视口 `overflow: hidden`，世界层是 0×0、`overflow: visible` 的 div，变换为 `translate(pan) scale(zoom)`，节点仍用世界坐标的 `left/top`，所以节点和视野都没有边界。
- 交互：拖空白处（左键或中键）平移；滚轮以光标为中心缩放（范围 10%–300%，`wheel` 用非 passive 原生监听，阻止外层面板滚动）；按钮以视口中心缩放；「适应」框选全部节点，单列过长时宽度优先、缩放不低于 40% 并从顶部开始；「复位」清空布局后再适应。视口获得焦点时方向键平移、`+`/`-` 缩放、`0` 适应。
- 节点：位移小于 4px 的按下抬起视为单击，选中节点；单击空白取消选中。Enter/空格打开原文（与双击相同）。方向键移动节点后若离开视野，视野跟随。选中素材时它发出的连线也高亮。
- 选中状态从别处变化（其他 tab、Agent 聚焦）且节点不在视野内时，视野居中到该节点；画布内单击产生的选中不移动视野。
- 拖动、平移和滚轮期间只更新组件本地状态，结束时（滚轮停 160ms 后）才写入 Store，避免每次 pointermove 重渲整个工作台。
- 每集的视野存在 Store 的 `productionViewport`（替换原 `productionZoom`），与节点布局一样只在本页保留；首次打开一集时框选全部节点并写入一次，之后改布局不会重新框选。提示文字改为「布局只在本页保留」，与实际行为一致。
- 外框改为在 `.oh-story-production` 内 flex 填满剩余高度（`:has()`），最低 420px；紧凑布局下控件允许换行。
- 原生冒烟测试新增：拖背景平移且节点世界坐标不变、滚轮改变缩放、「适应」后所有节点横向可见。

## Alternatives considered

- **只修 bug，保留滚动条视野**（给外层容器按 `内容范围 × zoom` 设尺寸、坐标钳制到 ≥0）— 最强理由：改动小，滚动条对不熟悉画布的用户最直观。不用：用户明确要求无限画布；钳制坐标仍然限制布局，滚动范围要跟着节点包围盒和缩放一起算，边界情况比 pan/zoom 状态更多。
- **引入现成画布库（如 React Flow）** — 最强理由：拖拽、缩放、小地图、连线路由都现成。不用：插件运行在 DSH 宿主提供的 React 里，新增运行时依赖会进入发布包并受 DSH 打包边界检查约束；本场景只有两列节点和贝塞尔连线，自己实现的数学不到百行，并有单元测试覆盖。

drama-skills 的 `2026-09-26-dashboard-benchmark.md` 否决过「无限画布或节点编排」，那是针对上游独立创作台的取舍，不约束本插件；本画布仍然只投影文档关系，不提交生产、不改创作文档。

## Consequences

- **收益**：任意坐标都可达；缩放围绕光标、不再错位；选中与 Agent 聚焦能把目标带进视野；拖动不再卡顿；键盘用户能平移、缩放、打开原文。
- **代价**：滚轮默认用于缩放，触控板双指滑动也会缩放而不是平移（平移需拖动空白处或方向键）。视野与布局仍然刷新即丢，跨刷新保存需要 DSH 提供持久的会话级 UI 状态。`VISUAL-*` 引用仍不被分镜解析为连线，视觉设定节点在画布上仍是孤立的，留作后续。500px 宽度下三栏布局本身只给画布约 130px，属于工作台整体布局问题。
