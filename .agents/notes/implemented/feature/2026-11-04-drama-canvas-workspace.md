# Agent Note: 短剧以 DSH 原生风格的媒体画布作为集级工作区

Status: implemented

## Problem

用户逐场景审阅现有短剧界面后，希望主流程自然、技术细节按需展开，并明确选择无限画布。固定步骤向导和独立深色应用方向被否决；最终批准沿用 DSH 导航、主题与原生 Chat 的浅色画布 Demo。现有生产入口挂在单份文件里，三栏把画布压缩得过窄，节点只显示标题与内部 ID，难以判断真实媒体成果。

## Decision

- 短剧增加集级工作区与独立剧集选择，默认媒体画布；文稿、目录和原生 Chat 可按需展开。目录与 Chat 不卸载宿主内容，不影响小说/游戏/视频。
- 故事、素材、镜头卡片投影现有文档和 workspace 图片/视频，版本与生产动作复用已有回调；不复制 Demo 的样例剧情或模拟输出。
- 画布使用多列布局、节点实际尺寸与准确适应；初次打开保持可读，其他来源的选中聚焦仍可达。布局/视野继续每集隔离。
- 主面自然化生产状态和名称，供应商环境与文档诊断放入制作详情。prepare-only、同任务明确确认、队列、取消和真实输出关联保持。
- 上下文入口通过 DSH 官方 SessionInput 聚焦 Composer；使用 requestDraftInitialization 的 whenDraftExists: keep 事务初始化自然语言上下文，宿主保护已有文字、附件与乐观发送中的草稿。

本决定扩展 [已有无限画布决定](../../implemented/feature/2026-10-08-infinite-drama-canvas.md)，改变其只有两列小型节点的呈现以及长列适应策略；画布只投影、原生 Chat 所有权与 Session UI 边界保持。

## Alternatives considered

- 固定阶段向导：用户明确否决，阻断自由探索。
- 独立深色应用：用户要求保持 DSH 插件身份与风格。
- 引入画布框架或第二套媒体后台：现有视野/任务/媒体协议可复用，无需新增依赖和事实来源。
- 删除发给 Agent 的完整投产契约来缩短 Chat：DSH 当前只支持原文发送；不以视觉简化牺牲同任务确认和参考输入规则。

## Consequences

短剧布局影响原生 Composer 留白与滚动，需要打包装入实际宿主验证；新增画布卡片不能拦截内部媒体控件或拖动时重渲整工作台。剧集切换必须保持稿件、选版、视野及任务隔离。
