# Agent Note: 按工作区选择显示的工作台

Status: implemented

## Problem

Issue #112 的短剧创作者不需要另外三个页卡，现有界面只能收起整个工作台。模型与 API 缺配置的提示也容易让人以为可以直接复用 DSH 对话模型。

## Decision

沿用 DESIGN.md 的导航、主题与配置归属约束，在四类工作台导航旁加入统一设置面板。显示项按浏览器工作区保存，默认全开、至少保留一个，隐藏当前项切到首个显示项；自动定位与文件跟随不恢复隐藏项。显示项属于按 cwd 唯一的页面级 store，以 `useSyncExternalStore` 订阅并写入 localStorage，不放入会话记忆，避免 A/B/A 切换恢复过期偏好；禁用站点存储时仍在当前页面共享最新选择。支持显示全部，保留项目、草稿、Skills 与运行中媒体。面板只说明 DSH 与媒体生产的配置边界，不存储凭据或增加宿主配置 API。

验证锁定默认导航与存储回归、显示项纯函数、设置 dialog 和共用导航接线，再在原生 DSH 浏览器中检查真实操作。改动不涉及固定上游资产、宿主 Agent 或制作任务协议。

## Alternatives considered

- 在每个页卡上加关闭按钮：容易误触，隐藏后仍需统一恢复入口。
- 只提供宿主静态配置：不适合创作者随时切换；无需服务端重启的浏览器偏好足够。
- 同时实现生产供应商配置中心：需要另行定义安全存储、执行世界与上游配置契约，本轮不把对话模型与媒体模型混为一谈。

## Consequences

浏览器禁用站点存储时只能保留当前页面会话的选择；不同浏览器不自动同步。原生集成检查覆盖隐藏当前项、恢复、键盘、刷新与跨工作区隔离。窄列小说导航给设置入口单独留行，避免页卡遮挡按钮；窄屏的会话切换检查在模态验证后回到桌面宽度，以免把宿主侧栏收起动画误当成设置失败。

## Verification

- 定向页卡、存储与 workspace store 测试通过；合并 main 的欢迎引导修复后，`pnpm verify` 的 36 个文件、270 项测试及 lint、类型、资产、边界、构建通过。
- `pnpm verify:release` 通过；原生 DSH `0.2.2-rc.1`、`0.2.0-rc.2`、`0.2.2-rc.3` 均返回 `ok: true` 与 `workbenchTabs: per-workspace-hide-restore-persist`。浏览器覆盖隐藏当前项、唯一显示项保护、Escape 与焦点返回、500px 面板边界、A/B/A 共享选择、刷新、跨工作区隔离与恢复全部后的当前项保持；实际截图已检查。
- 新会话通过宿主工作区按钮创建，以可见对话的 Session ID 变化和已选中的树项确认；blank 会话不渲染 `Session hierarchy`，不以其作为等待条件。侧栏动画中的点击仅在目标工作区已可见时接受为完成，异常仍保留脱敏后的真实堆栈。
