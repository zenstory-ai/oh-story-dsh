# workflow-volume.md：出卷纲（全书分段与卷纲）

作者要看全书怎么分段、这一卷怎么走时读本文件。同时读 [artifact-protocols.md](artifact-protocols.md)（大纲与卷纲模板）、`references/emotional-methods.md`「长篇单元情绪引擎」一节（排纲自查第 1 项）、`references/reader-contract-and-progression.md`（第 4 项）；有主对标时按下文「对标节奏迁移」读主对标的 `剧情/节奏.md`。设定从 `设定/` 读，不回翻对话。只交付卷纲时不读细纲文件。没有子代理时先把分卷与第一卷走向作为提案给作者，确认后落盘；主线事件整体放进提案，价格、数值这类刻度留空写「到该章问作者」；交付汇报最后一句建议新开对话说「出第1-10章细纲」，技术备注在它后面。

#### 全书体量与阶段总览（卷纲前置）

卷级大纲前先写全书体量与阶段边界，作为后续卷纲、细纲、日更补纲的共同约束。比例只作默认参考，必须按题材、目标字数和对标节奏调整，不能机械套模板。

```
## 全书体量与阶段总览

- 全书总章节数：{X} 章
- 目标字数：{X} 万字
- 全书情绪曲线：{压抑/期待 → 加压/反转 → 爽感/震撼 → 余韵/圆满；标注关键阶段}

### 阶段划分
1. 开篇期（第 {A}-{B} 章，参考 10%-15%）：核心任务 {立人设/立世界/埋主线钩子}；情绪基调 {压抑/期待/惊奇}；阶段结束时读者应建立 {对主角的认同 + 对主线冲突的期待}
2. 发展期（第 {A}-{B} 章，参考 50%-60%）：核心任务 {矛盾展开/支线并行/资源与关系升级}；情绪基调 {期待/紧张/间歇爽感}；阶段结束时读者应建立 {对核心反派或终局矛盾的迫切期待}
3. 高潮期（第 {A}-{B} 章，参考 20%-25%）：核心任务 {核心冲突爆发/多线收束/连续爽点}；情绪基调 {爽感/震撼/反转}；阶段结束时核心矛盾应 {基本解决或进入最终对决}
4. 收尾期（第 {A}-{B} 章，参考 5%-10%）：核心任务 {伏笔回收/关系落定/结局余韵}；情绪基调 {释然/感动/圆满}；阶段结束时主线伏笔应 {回收完毕，结局落定}

### 各阶段节奏公式
- 开篇期：核心任务 / 情绪基调 / 爽点密度 / 伏笔策略 / 冲突层级 / 阶段钩子 / 禁止提前释放
- 发展期：核心任务 / 情绪基调 / 爽点密度 / 伏笔策略 / 冲突层级 / 阶段钩子 / 禁止提前释放
- 高潮期：核心任务 / 情绪基调 / 爽点密度 / 伏笔策略 / 冲突层级 / 阶段钩子 / 禁止提前释放
- 收尾期：核心任务 / 情绪基调 / 爽点密度 / 伏笔策略 / 冲突层级 / 阶段钩子 / 必须回收清单

### 关键节点与钩子链
- 关键转折点：第 {X/Y/Z} 章，各自承担 {事件功能 + 情绪效果}
- 小/中/大高潮：小高潮第 {X/Y/Z} 章；中高潮第 {X/Y} 章；大高潮第 {X} 章
- 阶段钩子链：开篇期结尾指向发展期；发展期结尾指向高潮期；高潮期结尾指向收尾期
```

3. **伏笔与阶段边界**：本卷新埋哪些伏笔、上一卷待收的怎么处理；本卷在全书哪个阶段，可释放什么、必须压住什么（压住的写进细纲「本章禁止提前释放」）。
4. **契约四问**：按 `references/reader-contract-and-progression.md` 逐剧情单元过一遍，把 契约安全 / 需补强 / 契约破坏 写进单元卡「契约风险」；契约破坏 先修纲，需补强 补交换、铺垫或成本；两种都在规划汇报里告诉作者。不要求主角亲自完成每个动作。
5. **供给**：进入细纲层时按 workflow-outline.md 批次步骤 3 做供给自查。

## 节奏锚与对标迁移

### 关键点法（统一各尺度的节奏锚）

任意尺度（全书 / 卷 / 剧情单元 / 支线 / 章）都有五个关键点：开场、1/4、中点、3/4、结尾。其中 1/4、中点、3/4 是放关键情节的位置。关键情节三类：

| 类型 | 含义 |
|------|------|
| 情节逆转 | 发展在读者意料内，但主角的解决方式让人直呼精彩（装逼打脸、英雄救美） |
| 情节转折 | 意料之外（身份反转、敌变友、局势骤变） |
| 激励情节 | 全书或一卷第一个、与核心主线直接相关的命运改变时刻 |

不是每个尺度都把三处填满，但一卷至少在 1/4、中点、3/4 各安排一个关键情节，避免全程一个力度。

### 对标节奏迁移（卷纲定稿前做一次，无对标书可跳过）

1. **选段（以剧情单元为单位）**：在主对标里圈出本卷要对标的剧情单元序列——选段单位就是拆文产出的剧情单元（`剧情/{剧情标题}.md`）。检索顺序：先读主对标 `剧情/README.md`「剧情单元清单」（有清单则一书一文件，按「类型 / 桥段标签」直接命中同类）；无清单则在 `剧情/*.md` 里按「类型」行（第一键，必填枚举）+「桥段标签 / 套路框架位置」行（第二键）圈同类；仍无命中回退按章节范围圈段，全程不阻塞。多对标时按 `cross-book-recall.md` 大纲预算从副对标补同类条目。读取必备权威文件 `剧情/节奏.md`（爆发密度 / 爽点循环）；缺失时先修复或重跑拆文 Stage 3，不从摘要猜测节奏。本卷对标几个剧情单元 ≈ 本卷字数 ÷ 1.5-3 万。
2. **标关键点**：看对标这几个剧情单元在 1/4、中点、3/4 各放了什么关键情节，判为逆转 / 转折 / 激励。摘要里「类型=转折点」的情节点 + 基调突变（如温馨→压抑）就是关键点的确定性锚，不靠凭感觉；剧情单元的「结构分布」（铺垫/发展/高潮/收尾期）与「情节点索引」同为确定性锚。
3. **换素材**：保留对标的情绪链和功能位，把对象、场景、事件全换成自己的，禁止照搬具体桥段。功能位清单取必备权威文件 `剧情/情绪模块.md` 的可替换项；缺失时先修复，不生成替代清单。
4. **修正硬伤**：换素材前比对 `拆文报告.md`「不建议模仿」。对标若在某个关键点是弱处理（慢热留白、主角长期旁观等已知硬伤），迁移时要在该位置补一个缺的关键情节、或把后面的关键情节前置，而不是把弱处理一起抄过来——关键点该有的力度不能因为对标偷懒就跟着偷懒。
5. **排章 + 落卷纲**：把换好（并修正）的关键情节落到本卷相同相对位置——这里的 1/4·中点·3/4 是**卷尺度**（1/4≈总章×0.25、中点×0.5、3/4×0.75）；卷里有几个剧情单元时，每个剧情单元内部另有自己的铺垫→逆转→收尾，别和卷尺度的关键点混为一谈。关键点之间用普通推进章过渡，每个关键点之后按需插一章呼吸 / 关系章；写进卷纲「对标结构坐标」与情绪弧线的章节定位列，细纲承接时每章标章节定位。同时把选中的剧情单元以 {书名}《剧情标题》写入剧情单元卡「对标剧情参照」。

近精细远模糊：只精排当前卷，后续卷做粗坐标即可，不必一上来规划全书。

一个最小例子（demo《让你管账号，你高燃混剪炸全网》）：对标结构的 1/4 是“小人物拿出粗糙作品，无人看好”，中点是“作品爆火，体制内外同时关注”，3/4 是“专业力量进场替代，反而证明主角不可复制”。换到江晨这条军宣线后，1/4 落成他用手机拍《诸君，且听龙吟》、画质粗糙却先把军魂拍出来；中点落成视频引爆全网和参军热潮；3/4 落成专业团队高清重拍，却被周薄森当场指出“缺了灵魂”，张耀祖最终拍板继续用手机原版。保留的是“轻视→市场验证→权威替代失败→价值坐实”的情绪链，素材、场景和角色关系都来自本书。

## 章节定位与张弛（破「每章像短篇」）

一卷里章的压力本就该有高有低。这里的压力级指**爆发 / 冲突烈度**（复用悬念刻度 1 微 / 2 小 / 3 中 / 4 大 / 5 极），不是情感烈度——关系回收 / 泪目这类章可以压力低（爆发小）但情感强度顶满，情感烈度由卷纲情绪弧线的「情绪基调 + 强度」承载。章节定位由「这一章在它所属剧情单元里的位置」自然落出，不是另贴一套独立标签：剧情单元首章多为铺垫 / 共情，中段承载逆转，收尾爆发收束；黄金开篇、高潮结算 + 温情这类章可复合标注（如「高压 + 关系」）或留空。

| 章节定位 | 功能 | 压力级 | 卷内占比（均衡/长书基线，非硬配额） | 钩子要求 |
|------|------|--------|--------------------------|----------|
| 高压章 | 打脸 / 掉马 / 反转 / 高潮；关键点的关键情节落点 | 4-5 | 约 15-20% | 章尾强钩子；承载逆转 / 转折 |
| 普通推进章 | 主线推进、冲突升级、剧情单元中段 | 2-3 | 约 40-50% | 章尾中钩子；至少一个小爽点或期待递进 |
| 修炼试错章 | 实力 / 资源积累、能力铺垫、失败试错 | 2 | 约 5-10% | 进度钩子（差一点 / 即将突破），可无反转 |
| 关系回收章 | 感情线兑现、关系转折、身边人日常 | 2-3 | 约 5-10% | 情感钩子；拉扯仍带主线相关 |
| 低压生活章 | 高潮后喘息、关系升温、张弛调节 | 1-2 | 不超过约 10% | 允许弱钩子或仅情绪钩子；不强求反转 / 爽点 |
| 信息整理章 | 转场、设定交代、时间缝合 | 1 | 不超过约 5%，能并章就并章、少独立成章 | 允许无显性爽点；信息用「表演」承载；结尾给下一段目标 |

两条底线：

- **期待不断、爆发分布**。低压章可以没有爽点和反转，但每章都要给读者一个往下看的理由（微好奇、阶段目标、暧昧期待）。掉的是爆发烈度，不是往前的拉力——番茄追读尤其吃这条。
- **禁情绪母题扎堆**。比「每章像短篇」更隐蔽的疲劳源，是连续多章同一情绪母题高位运行（如连五章家国 / 泪目）——章节定位分得再开也救不了。排卷纲情绪弧线时逐行看相邻 3-4 章的情绪基调，同母题别连超 2-3 章；靠换情绪、换钩子方式、多线穿插来差异化，不是靠砍钩子。

题材分级（上面占比是均衡 / 长书基线，按题材分档）：番茄短平快 / 男频事业线，高压可到 30% 以上、呼吸章压到 5% 上下都正常，别拿基线去「补呼吸、砍高压」反而掉追读；女频 / 世情 / 追妻，人设关系容量大、关系 / 低压章可更多，但仍走情绪折线、不必每章三折。低压 / 关系章定位是看点（主角身边人的日常本身是订阅点），不是填充。

与字数目标的衔接：章节定位决定情节点功能与展开取舍，但不把每个情节点换算成固定字数，也不靠增点凑目标。写后由程序按双层长度带验收：明显欠长先判断已批准义务是否未实现，容量不足或不明确就协商自然长度、补纲或目标，绝不自动补写；明显超长可做一次不新增语义、逐项保留批准情节点与章尾钩子的净删型压缩，复检仍带外就停止，不进入循环删改。
