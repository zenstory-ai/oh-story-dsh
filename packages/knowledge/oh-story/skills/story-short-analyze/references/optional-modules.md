# 可选模块：同类对比、平台适配、详细节奏

作者要求或 Stage 6 之后需要时读本文件；不在主管道里。

## 方法

### 同类对比

将分析对象与同题材、同结构的其他作品对比：

| 维度 | 本文 | 对标作品A | 对标作品B |
|------|------|----------|----------|
| 情感曲线形态 | | | |
| 核心手法 | | | |
| 开头钩子强度 | 1-5 | 1-5 | 1-5 |
| 反转惊喜度 | 1-5 | 1-5 | 1-5 |
| 结尾余韵 | 1-5 | 1-5 | 1-5 |

**差异化亮点**：关键差异是优势还是劣势？

### 平台适配评估

| 平台 | 适配度 | 原因 | 调整动作 |
|------|--------|------|----------|
| 知乎盐言 | 高/中/低 | 偏重文笔和情感深度，8000-12000字 | |
| 番茄短篇 | 高/中/低 | 偏重节奏和爽感，5000-10000字 | |
| 七猫短篇 | 高/中/低 | 偏重故事完整性和可读性，6000-12000字 | |

#### 节奏指标

> 各维度数值只作文本描述。判断须回到具体节点、状态变化和后果，并在存在对标时与同题材、同平台样本比较。

| 维度 | 数值 | 判断 |
|------|------|------|
| 事件密度 | {N}个/千字 | {文本分布与真实状态变化} |
| 对话密度 | {X%} | {文本倾向、对白功能与无对白推进方式} |
| 冲突密度 | {X%} | {直接冲突与任务/证据/空间/关系压力的关系} |
| 信息密度 | {X%} | {读者模型变化与消化效果} |
