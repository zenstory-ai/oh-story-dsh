# Agent Note: 按工作区选择显示的工作台

Status: proposed

## Problem

Issue #112 的短剧创作者不需要另外三个页卡，现有界面只能收起整个工作台。模型与 API 缺配置的提示也容易让人以为可以直接复用 DSH 对话模型。

## Proposal

沿用 DESIGN.md 的导航、主题与配置归属约束，在四类工作台导航旁加入统一设置面板。显示项按浏览器工作区保存，默认全开、至少保留一个，隐藏当前项切到首个显示项；自动定位与文件跟随不恢复隐藏项。显示项属于按 cwd 唯一的页面级 store，以 `useSyncExternalStore` 订阅并写入 localStorage，不放入会话记忆，避免 A/B/A 切换恢复过期偏好；禁用站点存储时仍在当前页面共享最新选择。支持显示全部，保留项目、草稿、Skills 与运行中媒体。面板只说明 DSH 与媒体生产的配置边界，不存储凭据或增加宿主配置 API。

实现顺序：先锁定默认导航与存储回归，再增加显示项纯函数、设置 dialog 和共用导航接线，最后补原生 DSH 浏览器场景并运行完整验证。改动不涉及固定上游资产、宿主 Agent 或制作任务协议。

## Alternatives considered

- 在每个页卡上加关闭按钮：容易误触，隐藏后仍需统一恢复入口。
- 只提供宿主静态配置：不适合创作者随时切换；无需服务端重启的浏览器偏好足够。
- 同时实现生产供应商配置中心：需要另行定义安全存储、执行世界与上游配置契约，本轮不把对话模型与媒体模型混为一谈。

## Risks

浏览器禁用站点存储时只能保留当前页面会话的选择；不同浏览器不自动同步。原生集成检查需要覆盖隐藏当前项、恢复、键盘、刷新与跨工作区隔离。

## Verification

待定向单测、`pnpm verify` 与原生 DSH 浏览器验证。
