# Agent Note: 视频区以预览、叙事画布与文稿连接修改过程

Status: implemented

## Problem

用户希望沿短剧和游戏的方向设计视频区，要求流程自然、技术细节收起、保持 DSH 插件风格。现有视频区能播放真实产物，但文件查看与环境准备难以支撑逐段调整叙事、声音和原片核对。

## Decision

采用「预览 / 创作画布 / 文稿」。默认看成片、读分段解说，原声单独标记；需要修改时，把当前段落、版本和明确的时间基准带入 DSH 原生 Chat。画布表达观众疑问、原片、开场、转折、原声与结尾的关系，允许自由摆放。制作详情按需展开。

改稿与当前媒体分开，制作中继续保留旧版，新版由用户显式载入。只有真实产物提供可靠区间映射时才启用原片联动；输出时间不能直接充当原片时间。字幕预览与文件导出状态明确区分。

正式 VideoStudio 接入已打磨的方向。workspace 读取限定的权威文稿，纯函数投影真实段落、明确原声与剪辑映射；画布复用游戏区交互引擎，布局按项目保留。逐段编辑只改 narration，保留元数据并经共享缓冲区/CAS 保存。播放器跨视图保持挂载，离开预览暂停；可靠的角色对应保留核对位置。改稿可在段落与画布显示，明确标为配音未更新；文稿或媒体时间改变时不把新映射强加给旧视频。原型导入和模拟 Chat 不进入生产版本。

环境检查改为「制作详情」内按需查看，空项目也保留入口；该决定替代 [2026-10-19 环境前置展示](2026-10-19-example-entry-and-video-runtime-check.md) 中自动把环境行放入视频首页的方案，保留实际生产预检与依赖要求。用户现在要求技术细节收起，创作入口优先讨论内容。

## Alternatives considered

- 复制短剧镜头生产链：视频解说更需要围绕现有素材、讲法与声音反复核对。
- 多轨剪辑器：增加大量与 DSH 插件定位无关的编辑负担。
- 改字立即改变配音和成片：现有生产过程异步，文字与媒体版本需要明确分开。
- 直接用解说时间定位原片：剪辑会改变时间位置，必须依赖真实剪辑映射。

## Consequences

叙事投影限制段数、范围与有效字段，异常文件保持可读和可回到原文；解说时钟未知时不启用来源映射。没有映射的项目应保持基本读稿和播放能力。浏览器草稿与示例叙事仅服务设计评审，不能直接复制为生产事实。完整无障碍审计与实际付费模型制作不属于本轮验证。

## Verification

设计依据、官方研究链接与实现边界见根目录 DESIGN.md 的 Video workspace。本地原型的浏览器测试、媒体与截图证据保留在本次聊天的 `video-studio-demo/evidence/`。

- Playwright 在隔离 Chrome 中通过 11 组交互检查，无页面异常：实际播放暂停、输出 12 秒到原片 27 秒的对应、三种媒体切换、字幕、草稿与媒体分离、Chat 草稿保护、画布拖动与键盘、新版显式载入、实际 SRT 下载、各项目状态、本地导入隔离和 500px 界面。
- 单独核对「解说待确认」场景只展示解说计划，不显示不存在的当前成片卡片；空项目截图已留存。
- 原型阶段的仓库回归为 30 个测试文件、224 项测试。生产接入的最终验证结果在本节后续记录。
- 正式实现 `pnpm verify` 全部通过：lint、类型、四套固定资产、DSH 边界、发布脚本与上游更新脚本测试、33 个单测文件的 241 项测试及构建。浏览器包 372,734 字节，保留原有 400,000 字节预算，无新增依赖。
- `pnpm test:dsh` 在官方 DSH 0.2.1-rc.5 中返回 `ok: true`、`provider: local-fixture`、`videoStudio: preview-canvas-documents`。真实鼠标定位输出 0–2 秒与原片 2–4 秒，跨视图保持同一播放器和时间，画布拖动及项目隔离、逐段改稿保留未知元数据、实际文件 CAS 冲突恢复、原生 Composer 草稿保护、新版提示与显式载入、500px 鼠标和键盘切换、制作详情均通过。原有小说、短剧、游戏和真实 Role 工具回归同轮通过。
- 新版验证先经权威文件接口 CAS 更新成片清单，再用持续运行的本地响应任务触发工作区刷新；同时检查磁盘投影确为 v2、当前 tab 不被抢占、旧视频 DOM/时间不变，再明确载入新版。它验证文件与任务期间的界面合同，不代表真实配音或视频生成已执行。
- 浏览器验证发现并修复视频面板被宿主宽度拖柄遮挡的问题，沿用游戏面板的层级处理；窄屏键盘切到 Chat 同步打开原生会话，避免出现空白面板。正式截图见 `docs/images/video-narrative-workbench.png`、`docs/images/video-narrative-canvas.png`。
- 未调用付费生成，未修改固定上游资产，未发布包。
