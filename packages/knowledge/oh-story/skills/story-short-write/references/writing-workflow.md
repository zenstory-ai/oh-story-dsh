# writing-workflow.md：短篇写作工作流详解

Phase 2 设计任务的步骤与验收；Phase 4 精修清单在 workflow-revision.md。

## Phase 2 设计任务（框架确定后执行）

### 设计步骤

1. **设计信物 / 贯穿物**（可选，1-2 个）：见题材包招式库「信物翻转」（如追妻火葬场的信物意义翻转）
   - 填写：`- 第1次出现（第X节）：{场景}（{含义}）` 重复三次，含节号定位
2. **设计反派**（如有）：用 villain-and-reveal.md 反派模板
   - 填写：`{身份} + {动机} + {作恶方式} + {致命弱点} + {报应}`
3. **确定揭露方式**：从 villain-and-reveal.md 4 种真相揭露机制中选一种，写进 设定.md 反派设计区
4. **编写 小节大纲.md**：使用固定 12 列 Markdown 表格，每节 1 行，表头如下（列名和顺序不可改）：

   `| 结构段/五段功能 | 主事件 | 情节推进 | 情绪 | 人物/关系变化 | 因果/逻辑链 | 读者新获知什么 | 结尾承接/钩子 | 伏笔/物件 | 场景形态 | 对白作用 | 目标字数 |`

   下一行写 Markdown 分隔行，再逐节填写数据行。
   - `结构段/五段功能` 使用开头/铺垫/升级/反转/结尾（或起因/发展/转折/高潮/结尾），用于轻量对应长篇的内容概括，但不要套长篇完整章节蓝图
   - `人物/关系变化` 写本节前后变化；没有人物或关系变化时，写 `无（本节改变：信息/风险/资源/决定/行动/读者理解中的具体一项）`，不为填表硬造关系波动
   - `因果/逻辑链` 写 `原因 → 行动 → 结果 → 后果/新问题`，避免小节只是情绪堆叠
   - `结尾承接/钩子` 写本节如何接下一节；最后一节写结尾落点
   - `情节推进` 写本节一个或多个真实改变；不设数量下限，相关情节点允许由同一动作链或对话同时兑现，禁止为凑数量加入阻碍、配角反应、短回忆或意外
   - 有先后关系的推进单元用 `->` 连接，每个单元包含具体情节点描述+功能标签：
     `具体发生了什么{功能标签}` 如 `发现账单上多了一笔4800{发现}` / `把戒指冲进马桶{冲突}` / `他笑了{递进}`
     功能标签：`对话` / `冲突` / `伏笔` / `回忆` / `发现` / `递进`
     情节点描述要具体到"谁做了什么"，不能只写标签如`对话`或`冲突`
   - `场景形态` 写主要推进引擎，如行动、对话权力、证据核验、手艺、等待、空间压力或关系回落；不要求动静交替
   - `对白作用` 写对白实际改变的信息、策略、权力、关系或下一步行动；无对白时写明由哪种动作、证据、物件或任务推进，不设占比或话轮数量
5. **反转信息差验证**（outline 写完后、写作前必须验证）：
   - `short-reversal.md` 判为无反转 → 写明理由，改查报应因果或甜度期待是否经过铺垫并得到兑现；跳过以下揭示检查
   - 记录：读者在第几节知道真相？用「揭穿节号 ÷ 全文总节数」计算位置百分比，供核对节次和篇幅分配；百分比本身不是通过阈值
   - 揭示前：错误解释是否已影响至少一次重要决定？还没有 → 误判尚未参与剧情，应补行动后果或调整揭示位置
   - 揭示后：是否留出新的行动、关系变化或代价结算？只剩口头解释 → 提前揭示或压缩说明
   - 双层反转：第一层阶段答案后是否发生基于该答案的新行动？没有 → 两层只是连续口供，应拉开功能距离
   - 检查：至少有 1 条读者被成功误导的假线索（不是读者猜到后等角色追上来）
   - 检查：反转前是否铺垫了 ≥3 条指向真相的线索（线索要隐蔽，不是明示）
   - 验证：找一个人（或自我模拟）只看 outline，能否在反转前猜到真相？猜到 = 失败；回看才推得出是公平，不算失败
6. **伏笔回查清单**（outline 写完后、写作前检查）：
   - 列出结尾所有关键元素（物件/信息/角色/关系变化）
   - 每个结尾元素在前文有 ≥1 次铺垫？没有 = 天降，必须补铺垫
   - 用了贯穿道具时，三次出现完整？（第 1 次出现在铺垫段，第 2 次出现在反转段，第 3 次出现在结尾段）
   - 铺垫节号与揭穿节号的间距 ≥ 3 节（间距太短铺垫无效）

### 设定.md 内容构成

核心框架（含平台基调、人设速写）+ 作者已定 + 题材招式 + 反转铺垫（信息差验证与伏笔回查结果）+ 贯穿道具 + 反派设计与揭露方式 + 对标摘要；写正文只读它与小节大纲，所以构思里定下的都要写进来。贯穿道具追踪表：
`| 物件 | 第1次出现(节号/含义) | 第2次出现(节号/含义) | 第3次出现(节号/含义) |`
