# Agent Note: 短剧生产视图统一视觉；生成环境与格式提醒收进状态胶囊

Status: implemented

## Problem

2026-10-08 用户审阅「生产」视图时反馈「好乱」。逐页截图（1440×900，中栏约 510px）看到的问题：

- 每个 tab 顶部都有约 190px 的「生成环境」面板：五个红点、整行环境变量名（`MINIMAX_VIDEO_RESOLUTIONS` 等）、临时目录全路径，未配置供应商是只写提示词时的正常状态，却以错误的红色占据首屏。下面紧跟一个橙色边框的「格式提醒」框。
- 镜头卡占位图 132px 高的灰块，ID、时长、参考链接都是同一种蓝色链接样式，层级不清；素材卡把五行英文提示词原文铺在卡片上，「人物」小字悬在图片下方。
- 「成片」行的镜头 ID 在窄列里逐段换行（`SHOT-` / `EP001-` / `001`）；「任务」空状态只是一句居中文字加一个说明框。
- 画布的说明框与缩放控件互相遮挡。

## Decision

- `drama-production-view.tsx` 的 `ProductionStatus` 取代原环境面板和格式提醒 `<details>`：一行两个胶囊按钮（`aria-expanded`），默认收起。环境胶囊显示「N/M 供应商已配置」，Python 低于 3.10 时改为「需要 Python 3.10+」；点开是逐行的供应商表（状态点、模态、名称、缺失变量以 mono 小标签列出），Adapter 配置只显示文件名，全路径放在 `title` 并提供「复制路径」。格式提醒胶囊点开是「文件:行号 + 说明」两列列表。一次只展开一个。
- 状态色只用小圆点：全部配置为绿色，部分配置为黄色，一个都没配是空心灰点（正常状态，不是错误），Python 不满足或 Adapter 写入失败才用红色。
- 卡片统一：12px 圆角、8px 内边距，ID 用 mono 灰字（悬停变品牌色），时长是胶囊，「起/终」是浅色方块标签，就绪状态绿色胶囊，参考链接是描边 mono 标签；主操作用浅品牌色底。镜头占位是虚线斜纹框；素材卡的类型标签浮在媒体左上角，按人物/场景/道具着不同浅色，提示词收到 3 行。
- 「成片」行改为 `序号 | 缩略图 | ID 与素材选择上下排列 | 上下移按钮竖排`，ID 不再换行；紧凑布局下素材选择占满第二行。阻塞项是带圆点的浅黄提示框；「合成成片」是实心主按钮。
- 「任务」说明改为无框灰字，空状态改为虚线框里的标题加说明；项目媒体库与素材卡同一套卡片语言。
- 画布说明与缩放控件放进同一行工具栏，缩放控件是分段按钮组。
- 测试依赖的类名与文案（`.oh-story-production-summary`、`N 个阻塞项`、`缺少素材`、`合成成片`、`.oh-story-sequence > ol > li strong` 等）保持不变。

## Alternatives considered

- **环境面板保留展开，只压缩排版** — 最强理由：第一次使用的人一眼就能看到「DeepSeek 只写提示词，媒体由供应商 API 生成」这条关键信息。不用：这条信息在五个 tab 上重复占据首屏，真正工作的镜头卡被推到下面；胶囊上的「0/5 供应商已配置」已经提示了状态，详情一次点击可达。
- **未配置供应商继续用红点** — 最强理由：提醒用户生产会停在供应商调用前。不用：很多创作者只用 Agent 写提示词，未配置是预期状态；红色应该留给真正阻塞的 Python 版本与 Adapter 写入失败。

## Consequences

- **收益**：首屏回到镜头/素材本身；各 tab 用同一套间距、圆角、字体层级与状态色；暗色模式下同样成立。
- **代价**：未配置供应商的说明需要点开胶囊才看得到。500px 窗口下三栏布局只给中栏约 130px，这是工作台整体布局问题，本次只保证控件在窄列里换行、不被裁切，没有改三栏策略。
