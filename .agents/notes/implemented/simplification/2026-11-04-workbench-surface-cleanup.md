# Agent Note: 移除试玩笔记并精简视频与游戏工作台

Status: implemented

## Problem

用户核对 PR #104 截图后认为试玩笔记不必要，栏目标题与信息元素堆叠，重点要求解说视频页面清爽。视频预览在播放器之外叠了项目标题、时间信息栏、段落概览和「正在核对」条，右栏还有说明句和免责声明，同一信息反复出现，播放器反而不够突出。

## Decision

移除试玩笔记的入口、抽屉、专属协议与 `/oh-story/game-notes` 路由，反转 [游戏区设计笔记](../feature/2026-11-04-game-playable-workspace-design.md) 中的试玩笔记部分，其余决定不变。试玩感受直接进原生 Chat。磁盘上已有的 `PLAYTEST_NOTES.md` 不删不改，作为普通项目文件出现在文稿「更多项目文件」，继续走共享缓冲区与版本保存。

每项信息只留一处，解说视频以播放器为主，修改 [视频区设计笔记](../feature/2026-11-04-video-narrative-workspace-design.md) 的呈现方式，不改其时间基准与版本决定：

- 项目名只在选择器出现；视频预览、游戏试玩都不另设标题，游戏工具栏去掉品牌字。
- 视频工具栏宽屏合并为一行，工作台不超过 800px 时回到两行，窄屏布局不变。
- 「解说稿」「讨论当前画面」移入版本栏，全屏时隐藏，因为解说稿面板不在全屏元素内。
- 时间交给原生控件；状态条只在制作中或核对区间时出现，`role="status"` 容器保持挂载，保证状态变化能被读屏播报。
- 段落定位和逐段讨论都在解说稿内，完整文稿走「文稿」tab。没有媒体时只留一个空状态。
- 画布工具条改放操作提示；原片、成片卡去掉复述按钮的句子，并同步降低卡片高度。`CreativeCanvas` 的 `title`、`description` 不再有调用方，一并删除。
- 文稿页去掉重复眉题和目录标题；「修改后需要继续制作」只在编辑或有草稿时显示。

切换控件按职责收敛，只删除操作同一状态的入口：

- 720px 以下，游戏、视频的 Chat 按钮与「制作 / 对话」操作同一面板状态，隐藏 Chat 按钮，只为它存在的宽度分支一并删除。短剧窄屏没有「制作 / 对话」，Chat 按钮保留。
- 窄屏工具栏收成两行，更窄时才折行；游戏不再为浮动开关空出一整行。
- 四类工作台切换共用 `WorkbenchModeTabs`，桌面降为次级尺寸，与观察面 tabs 区分主次。游戏的 × 移到它旁边，短剧去掉品牌字。
- 短剧外层「画布」实际是包含画布、素材、生成记录、成片的制作区，改名为「制作」，内层「画布」不变；外层 tabs 复用 `handleTabKey` 支持方向键。内部状态值与导航结构不变。
- 工作台切换、观察面 tabs、版本 tabs、宿主 Chat / Trajectory 职责不同，全部保留。

## Alternatives considered

- 把四类工作台切换收进下拉：少一排，但跨工作台切换多一步，且折叠后看不到其余工作台。
- 窄屏去掉「制作 / 对话」、保留 Chat 按钮：单个按钮表达不了两个面板的选中状态，也失去 tab 键盘语义。

- 只隐藏笔记入口、保留路由与协议：留下没有界面的写入面和维护成本。
- 删除或迁移 `PLAYTEST_NOTES.md`：可能丢失创作者内容，且没有必要。
- 把解说稿收进默认关闭的抽屉：页面更空，但边看边读是视频区的主要工作方式。
- 去掉版本栏的「讨论当前画面」：Chat 按钮不带时间和版本上下文，不能替代。

## Consequences

笔记不再关联试玩版本。该功能未发布到 `main`，没有已发布版本的迁移问题。Chat 展开或工作台变窄时解说稿不常驻，段落定位要先点「解说稿」打开浮层，比段落概览多一步。

视频与游戏的文档截图已换成 smoke 夹具的真实界面，游戏试玩图不再是《青石巷来信》的成品画面，发版前可考虑用演示工程重拍。`game-studio-jin-ping-mei.png` 仍是改动前的工具栏。短剧外层切回「制作」时仍回到内层画布，不记住上次所在的素材、生成记录或成片。
